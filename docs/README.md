# Documentation

This directory contains project documentation for the secure file transfer demo.

## Guides

- [Usage Guide](usage.md): prerequisites, local setup, server/client workflow, and troubleshooting.
- [Testing Guide](testing.md): automated test coverage, commands, and suggested future tests.

## Security scope

The project is a local educational demo. It shows HTTPS transport and SHA-256 integrity reporting, but it does not implement production concerns such as authentication, authorization, upload size limits, malware scanning, certificate rotation, or durable audit logging.
